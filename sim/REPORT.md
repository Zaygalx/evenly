## Bugs this simulation found and fixed in the real app

1. Memory listing could silently miss records (single semantic recall).
   Fixed with a per kind recall sweep at a wide distance.
2. Hydration rebuilt every expense as accepted with its proposed shares,
   making undecided proposals permanently undecidable on fresh instances.
   Fixed: decision memories now restore true status and shares.
3. Household settings (exchange rate, memory switch) were never persisted
   to Walrus, so cold instances lost them and refused settlements.
   Fixed: settings now append a household record and rebuilders take the
   latest.
4. Pending settlements were never written to Walrus, so only the creating
   instance knew they existed. Fixed: creation appends a pending record,
   detection appends a settled one, latest per id wins.
5. The settlement backfill used the retired JSON-RPC transaction query
   (the gateway answers HTTP 404). Fixed: backfill now reads the public
   Sui GraphQL indexer; the Tatum checkpoint stream remains the live layer.
